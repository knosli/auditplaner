Liest aus einer Einsatzliste, wie viel Personal pro Baustelle in der Zielwoche eingeteilt ist, und schlägt vor, Baustellen ohne Personal zu pausieren bzw. wieder zu aktivieren. Die Datei wird nur lokal im Browser gelesen – nur die Baustellen-Zusammenfassung (kein Personenname) wird gespeichert.

Diese Datei erzeugst du separat mit dem Einsatzlisten-Konverter (lokales Tool, verarbeitet die Original-Einsatzlisten mit Namen/Nummern und exportiert nur die anonyme Zusammenfassung). Hier wird nichts mehr direkt aus Excel/PDF gelesen.

Sammelbox

Einmaliges Setup nötig? (falls Sammelbox nicht synct)

Falls die Sammelbox nicht zwischen Geräten synchronisiert, fehlt eventuell die Spalte in Supabase. Einmalig im Supabase SQL-Editor ausführen:

ALTER TABLE audit_state ADD COLUMN IF NOT EXISTS "piCollectBox" text;
ALTER TABLE audit_state ADD COLUMN IF NOT EXISTS "auditTarget" integer;
ALTER TABLE audit_state ADD COLUMN IF NOT EXISTS "tempWorkers" text;
ALTER TABLE audit_state ADD COLUMN IF NOT EXISTS "ferienWunsch" text;
ALTER TABLE audit_state ADD COLUMN IF NOT EXISTS "orsKey" text;
